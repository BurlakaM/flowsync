# 31. Файли

- **Статус:** прийнято

- **У журналі плану:** D31 (`docs/ARCHITECTURE_PLAN.md`, розділ 3)

## Рішення

Завантаження через API (`multer`): тип за байтами, до 2 МБ, SVG заборонено; зберігання в S3-сумісному сховищі (`@aws-sdk/client-s3`), віддача лише учасникам проєкту. Dev-сховище — RustFS (образ MinIO більше не публікується безкоштовно)
